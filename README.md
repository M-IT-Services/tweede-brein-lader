# Tweede Brein, lader voor Koppelingen

Pluginbron `m-it` van M-IT Services met de plugin `tweede-brein` (lader 1.0.2 voor Koppelingen).

Dit is alleen de lader. Hij meldt de medewerker aan met het eigen Microsoft-account en haalt de werking op bij de kernserver van M-IT. Dat lukt alleen met een geldige licentie. De lader voert alleen code uit die M-IT heeft ondertekend.

Installatie en gebruik gaan via M-IT Services: https://www.mitservices.nl/ai-assistent
